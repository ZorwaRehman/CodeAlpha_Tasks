# Task 1: Modern E-Commerce Store

A responsive, feature-rich E-Commerce web application built with React, TypeScript, and Tailwind CSS.

## Features
- Product Catalog: High-resolution cards with pricing, discounts, ratings, and stock status.
- Dynamic Search & Filtering: Real-time search, category filters, price sorting, and rating filters.
- Cart & Wishlist: Real-time totals, quantity controls, shipping calculator, and 1-click wishlist.
- Checkout Flow: Multi-step checkout modal with shipping address inputs, payment selection, and order summary.
- Responsive Design: Optimized for mobile, tablet, and desktop screens.

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Lucide React

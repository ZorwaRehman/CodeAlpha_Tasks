# Task 2: Pulse - Mini Social Media Platform

A full-stack social media application built with React 19, TypeScript, Tailwind CSS, and Express.js.

## Features
- Rich Post Creation: Text updates with hashtag styling, media links, and interactive live polls.
- Dual-Feed System: For You (global discovery) and Following (personalized feed).
- Social Interactions: Follow/unfollow system, post liking, bookmarks, reposts, and nested comment replies.
- User Profiles: Customizable banner, avatar, bio, location, website, and activity tabs (Posts, Media, Likes, Saved).
- Notifications & Profile Switcher: Instant activity alerts and demo multi-profile switching.
- Full-Stack Architecture: Express.js backend with REST API and JSON persistence.

## Tech Stack
- Frontend: React 19, TypeScript, Tailwind CSS, Lucide React, Motion
- Backend: Node.js, Express.js (REST API)
